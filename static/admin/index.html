Comment ajouter une œuvre ?

01Ouvrir l'éditeur

Connectez-vous au compte autorisé à modifier le site.

02Créer une œuvre

Ouvrez « Œuvres », ajoutez titre, catégorie, photo, description et détails.

03Enregistrer

Enregistrez : le site sera mis à jour automatiquement après le déploiement.

Première installation uniquement :

Le propriétaire du site doit publier ce projet sur GitHub et Netlify, puis connecter son dépôt à Pages CMS. Tant que cette étape n'est pas faite, le bouton ouvre l'éditeur, mais aucun site à modifier n'y apparaîtra.
